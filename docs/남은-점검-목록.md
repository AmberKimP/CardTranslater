## 2. 실제 앱에서 직접 써 보기 (카드 프로젝트)

1.19.x 새 기능은 테스트로만 확인했다. 실제 카드에서 다음을 확인한다.

**2B 카드 보기 · 아이콘 자리 잡기**
- [ ] 다른 아이콘과 겹치게 상자를 그리면 “겹친 아이콘 (N개) 흡수” 버튼이 켜지고, 누르면 그 자리가 현재 아이콘으로 합쳐진다.
- [ ] “둘로 나누기”: 아이콘의 한쪽 부분을 그리고 누르면 두 자리로 나뉘고, 원문에 `[[?]]`가 하나 늘어난다.
  나뉜 뒤 번역·한글 넣기에서 아이콘 순서가 맞는지 본다.
- [ ] “이 자리로 저장”으로 여러 아이콘이 한 세트로 합쳐질 때 창이 닫히지 않고, 합쳐진 모습으로 화면이 바뀐다.

**② 아이콘 정의 — 자동 세트**
- [ ] 좌우로 붙은 아이콘(`[[?]][[?]]`)은 자동으로 한 세트가 된다.
- [ ] 위아래(다른 줄)로 이어진 아이콘은 자동으로 합쳐지지 않는다. 2B에서 상자로 함께 감쌌을 때만 “한 세트로” 질문이 나온다.

**창 번호 · 디버깅 모드**
- [ ] 모든 창 제목 앞에 창 번호(예: `2B`)가 보인다.
- [ ] Ctrl+D: 버튼에 코드가 보이고, 누르면 코드가 복사되며 동작은 하지 않는다. 다시 Ctrl+D로 원래대로 돌아온다.

**0F 영역 지정**
- [ ] 카드 그림과 영역을 여러 번 누른 뒤 앱을 닫아도 오류 없이 끝난다 (1.19.1에서 고친 문제).
