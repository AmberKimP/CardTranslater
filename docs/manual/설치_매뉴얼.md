# CardTranslater 설치 매뉴얼

보드게임 카드 PDF를 한글로 옮기는 프로그램 CardTranslater를 Windows PC에 설치하는 방법입니다.
설치가 끝나면 [처음 설정 매뉴얼](처음_설정_매뉴얼.md)을 따라 Claude 연결을 한 번 해 주세요.

---

## 1. 준비물

| 항목 | 내용 |
|---|---|
| PC | Windows 10 또는 11, 64비트 |
| 디스크 공간 | 약 1.5GB (프로그램 약 400MB + 글꼴 약 250MB + Claude Code 약 400MB + 작업 파일) |
| 인터넷 | 필요 (Claude로 글자를 읽고 번역합니다) |
| Claude 사용 방법 | 둘 중 하나 — **Claude 유료 구독(Pro·Max)** 계정, 또는 **Anthropic API 키** (자세한 것은 처음 설정 매뉴얼) |
| 관리자 권한 | 필요 없습니다 (내 사용자 폴더에 설치) |

받을 파일은 두 개입니다.

| 파일 | 크기 | 언제 설치 |
|---|---|---|
| `CardTranslater-Setup-<버전>-<날짜>.exe` | 약 110MB | 처음, 그리고 업데이트할 때마다 |
| `CardTranslater-Fonts-<번호>.exe` | 약 40MB | 처음 한 번 (글꼴 번호가 바뀔 때만 다시) |

> 프로그램 설치 파일에는 기본 글꼴(본고딕)만 들어 있습니다. 한글 글꼴 58개(명조·손글씨·제목용 등)는
> 글꼴 설치 파일에 따로 있습니다. 글꼴은 자주 바뀌지 않으므로 업데이트 때마다 다시 받지 않아도 됩니다.

---

## 2. 프로그램 설치

1. `CardTranslater-Setup-….exe`를 두 번 누릅니다.
2. **"Windows의 PC 보호"** 파란 창이 나오면 (서명하지 않은 프로그램이라 나오는 경고입니다)
   - **추가 정보**를 누르고 → **실행** 버튼을 누릅니다.
3. 설치 창에서
   - 바로가기: "바탕화면에 바로가기 만들기"를 원하면 체크합니다.
   - **설치**를 누릅니다. 설치 위치는 바꾸지 않아도 됩니다 (`C:\Users\<사용자>\AppData\Local\Programs\CardTranslater`).
4. 마지막 화면의 **"CardTranslater 실행"** 체크는 **끄고** 마침을 누릅니다 (글꼴을 먼저 설치하는 것이 좋습니다).

## 3. 글꼴 설치

1. `CardTranslater-Fonts-….exe`를 두 번 누릅니다.
2. "Windows의 PC 보호"가 나오면 위와 같이 **추가 정보 → 실행**.
3. **설치**를 누릅니다. 고를 것은 없습니다.
   - 글꼴은 `C:\Users\<사용자>\AppData\Local\CardTranslater\fontpack`에 들어갑니다.
   - Windows 글꼴 폴더에는 설치하지 않으므로 다른 프로그램(워드 등)에는 보이지 않습니다. CardTranslater만 씁니다.
4. CardTranslater가 켜져 있었다면 끄고 다시 켜야 새 글꼴이 보입니다.

> 글꼴을 설치하지 않아도 프로그램은 동작합니다 (본고딕만 씀). 이때 ⑧ 한글 넣기의 글꼴 고르기 창 위에
> "앱 글꼴 N개가 설치되어 있지 않아…" 안내가 나옵니다.

### 내가 가진 글꼴 넣기 (선택)

목록에 없는 한글 글꼴 파일(.ttf·.otf·.ttc)을 쓰고 싶으면 **내 글꼴 폴더**에 넣습니다.

1. ⑧ 한글 넣기의 글꼴 고르기 창에서 글꼴 칸 맨 아래 **글꼴 추가…** 를 누릅니다.
2. **내 글꼴 폴더 열기**를 누르면 폴더가 열립니다 (`문서\CardTranslater\내 글꼴`, 데이터 폴더를 바꿨다면 그 안).
3. 글꼴 파일을 그 폴더에 복사합니다 (하위 폴더도 됩니다).
4. **목록 새로 고침**을 누르면 "내 글꼴 폴더" 아래에 나오고, 위 검색 칸에서도 찾을 수 있습니다.

- 한글이 없거나 PDF에 넣는 것이 허락되지 않은 글꼴(라이선스)은 목록에 나오지 않고, 창 아래에 이유가 나옵니다.
- 글꼴은 PDF에 들어가므로, 결과물을 배포한다면 그 글꼴의 라이선스가 허락하는지 확인하세요.

## 4. 실행

- 시작 메뉴 또는 바탕화면의 **CardTranslater**를 누릅니다.
- 처음 켜면 **"어떤 방식으로 Claude를 쓸까요?"** 창이 나옵니다 → [처음 설정 매뉴얼](처음_설정_매뉴얼.md)로 이어집니다.

---

## 5. 업데이트

1. CardTranslater를 끕니다 (켜 두면 설치 프로그램이 끄라고 묻습니다).
2. 새 `CardTranslater-Setup-….exe`를 설치합니다. 위 2번과 같습니다. 프로젝트·용어집·설정·로그인은 그대로 남습니다.
3. 새 글꼴 설치 파일(`CardTranslater-Fonts-<번호>.exe`)을 함께 받았을 때만 글꼴도 다시 설치합니다.
   번호가 같으면 다시 설치하지 않아도 됩니다.
4. 무엇이 바뀌었는지는 프로그램의 **도움말 > 릴리스 노트…** 에서 볼 수 있습니다.

> **1.6.1 이하에서 1.6.2 이상으로 올릴 때**: 이때부터 글꼴이 따로 나왔으므로 글꼴 설치 파일을 꼭 한 번 설치하세요.

## 6. 제거

Windows **설정 > 앱 > 설치된 앱**에서
- **CardTranslater** — 프로그램
- **CardTranslater 글꼴 묶음** — 글꼴

을 각각 제거합니다. 아래는 제거해도 남습니다 (필요 없으면 직접 지웁니다).

| 남는 것 | 위치 |
|---|---|
| 프로젝트·게임(용어집·검수 엑셀)·결과 PDF | `문서\CardTranslater` (설정에서 바꿨다면 그 폴더) |
| Claude Code | `C:\Users\<사용자>\.local\bin\claude.exe` (다른 데서도 쓰면 지우지 마세요) |
| 앱이 대신 설치한 도구(있을 때만)·로그 | `C:\Users\<사용자>\AppData\Local\CardTranslater` |
| Claude 로그인 정보 | `C:\Users\<사용자>\.claude` (Claude Code가 관리) |

---

## 7. 설치할 때 문제가 생기면

| 증상 | 해결 |
|---|---|
| "Windows의 PC 보호"에 **실행** 버튼이 없다 | **추가 정보**를 먼저 눌러야 실행 버튼이 보입니다 |
| 백신이 설치 파일을 막는다 | 받은 곳이 맞는지 확인한 뒤 백신에서 "허용"하거나 잠시 예외로 둡니다 |
| "다른 프로그램이 파일을 쓰는 중" | CardTranslater를 끄고 (작업 관리자에서도 확인) 다시 설치합니다 |
| 글꼴 고르기 창에 글꼴이 몇 개 없다 | 글꼴 설치 파일을 설치하고 프로그램을 다시 켭니다 |

그래도 안 되면 프로그램의 **도움말 > 로그 묶어서 저장…** 으로 만든 zip 파일을 보내 주세요
(API 키는 가려서 저장됩니다).
